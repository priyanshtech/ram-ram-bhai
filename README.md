# Konvert AI

AI customer support dashboard with a Next.js frontend and FastAPI backend.

WhatsApp automation supports one account per workspace, searchable on/off toggles for individual chats, text replies using the existing assistant and knowledge base, and a master pause control.

Run the complete stack with Docker using [Docker setup](docs/docker.md).

See [local WhatsApp setup](whatsapp-connector/README.md) and [backend setup](backend/README.md).
